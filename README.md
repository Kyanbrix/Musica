# 🎵 Musica

Musica is a feature-rich, high-performance Discord music bot built with Java. It provides seamless audio playback, playlist management, and high-quality voice channel integration for your Discord server.

## ✨ Features

* **High-Quality Audio:** Stream music directly from platforms like YouTube, Spotify, and SoundCloud (powered by Lavaplayer/similar audio engine).
* **Queue Management:** View, shuffle, loop, and manage your server's music queue effortlessly.
* **Stable & Fast:** Built on Java to handle multiple concurrent voice sessions without lag.

## 🛠️ Tech Stack

* **Language:** Java (21)
* **Dependency Management:** Maven (`pom.xml`)
* **Discord API:** JDA (Java Discord API) *[Update this if using a different wrapper]*
* [Lavalink](https://github.com/lavalink-devs/Lavalink)
